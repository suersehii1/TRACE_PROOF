# 고객 시연 영상 대본과 장면 구성

실제 실행 화면과 가상 데이터로 제작했습니다. 여성 합성 음성 ko-KR-SunHiNeural을 사용했습니다.

## 00:00 장비 변경 검증을 한눈에

장비 소프트웨어를 바꾼 뒤에도, 고객에게 약속한 데이터가 제대로 나올까요? 트레이스프루프의 실제 화면으로 확인해 보겠습니다.

## 00:12 고객이 겪는 문제

로그, 데이터 항목표, 시험 결과를 따로 확인하면 단위 변경이나 누락을 놓치기 쉽습니다. 이 도구는 흩어진 근거를 대조해, 담당자가 다시 확인할 부분을 보여 줍니다.

## 00:27 01  장비 데이터 등록

먼저 장비 데이터를 등록합니다. 이 시연에서는 가상 장비가 원본 파일을 실제 에이치티티피 통신으로 보냅니다. 제이슨 파일을 직접 올릴 수도 있고, 같은 원본은 중복 저장하지 않습니다.

## 00:45 02  검사할 기준 확인

단위, 허용 범위, 수집 간격과 최소 표본을 기준표로 확인합니다. 기준을 정하지 않은 항목까지 정상이라고 추정하지 않습니다. 고객과 합의한 범위를 검사하는 방식입니다.

## 01:02 03  변경 전후 비교

기준 버전과 수정 버전을 고르고 검증을 실행합니다. 같은 장비와 같은 운전 조건의 자료를 비교하며, 기준 데이터 자체에 문제가 있으면 승인도 막습니다.

## 01:16 04  문제를 빠르게 좁히기

결과는 통과, 실패, 판단불가, 미실시로 나뉩니다. 이 결함 자료에서는 단위 충돌과 유량 누락 등이 드러납니다. 필터로 문제 항목을 좁혀, 모든 파일을 처음부터 다시 찾는 일을 줄이도록 돕습니다.

## 01:36 05  원본으로 확인

원본 확인을 누르면 기대 기준과 실제 관측값, 해당 데이터 행이 함께 보입니다. 여기서는 섭씨 기준과 화씨 데이터가 다릅니다. 결과만 전달하는 대신, 같은 근거로 개발팀과 품질팀이 논의할 수 있습니다.

## 01:55 06  조치와 검토 기록

필수 문제가 남아 있으면 승인할 수 없습니다. 담당자는 보류 사유와 후속 조치를 기록합니다. 누가 무엇을 확인했는지 남아, 다시 설명하거나 자료를 요청하는 과정을 정리할 수 있습니다.

## 02:13 07  수정 후 다시 검증

이제 수정이 끝난 버전으로 새 검증을 실행합니다. 필수 검사가 통과하면 담당자가 근거를 확인하고 검토를 승인합니다. 범위를 정하지 않은 진동 검사는 미실시로 남겨, 확인하지 않은 내용을 숨기지 않습니다.

## 02:32 08  보고서로 전달

보고서에는 버전, 기준, 판정과 원본 해시, 검토 이력이 모입니다. 브라우저에서 피디에프로 저장하고, 검사표와 원본도 내려받을 수 있습니다. 고객에게 어떤 범위를 확인했는지 설명할 자료가 됩니다.

## 02:51 09  현장에서도 같은 화면

화면은 휴대폰 크기에도 맞춰집니다. 현장에서 데이터를 확인하고, 원본과 검토 상태를 볼 수 있습니다. 같은 네트워크에서 접속할 수 있으며, 실제 장비 연결은 별도 어댑터로 확장합니다.

## 03:09 고객 적용의 시작

기존 시험 도구를 유지하면서, 데이터 대조와 검토 자료 정리를 보완합니다. 장비 한 모델의 실제 업무로 효과를 확인해 보세요. 이 영상은 가상 데이터 시연이며, 고객 인수 합격이나 수율 개선을 보장하지 않습니다.
