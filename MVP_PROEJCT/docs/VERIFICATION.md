# 검증 결과

검증일: 2026-10-30. 사용자 PC의 Docker Desktop Linux 엔진에서 실제 컨테이너를 빌드·실행했습니다. 외부 고객 공정이나 실제 장비를 시험한 결과는 아닙니다.

## 실행 환경과 확인 항목

| 항목 | 확인 |
|---|---|
| Compose 구성 | frontend·backend·db·simulator 4개 서비스 |
| 데이터베이스 | PostgreSQL 16, named volume에 원본·검증·검토 저장 |
| 전송 | simulator가 RAW_DATA 3종을 HTTP 장비 수신 API로 전송 |
| 화면 | Vue 3 프로덕션 빌드, Nginx 배포, 실제 Chrome 접속 |
| 기본 주소 | localhost:8088. 8080은 다른 프로세스가 사용 중이라 회피 |
| 외부 의존성 | 업무 화면에서 외부 CDN·AI 호출 없음 |

## 자동 시험

백엔드 단위·PostgreSQL API 통합 시험은 `backend/tests/`에 있습니다.

최종 검사 엔진 1.0.1에서 **12개 시험이 통과**했습니다. 컨테이너 4개 모두 healthy 상태였고, 백엔드 재생성 후 원본 3종과 기존 검증·검토 이력이 유지됨을 확인했습니다. 브라우저 시험도 PASS, JavaScript 예외 0건으로 종료됐습니다. 테스트 클라이언트의 AnyIO 호환성 관련 사용 중단 예고 경고 1건은 있었지만 시험 실패는 없었습니다.

- 정상 자료의 필수 검사 통과 및 비필수 미실시 유지.
- 단위 충돌, 유량 누락, 중복시각, 작업 번호 오류, 범위 초과, 시험 버전 불일치 탐지.
- 잘못된 기준 데이터가 있으면 정상 수정 자료도 승인 차단.
- 다른 운전 시나리오 비교 차단, 미등록 항목 확인 필요 처리.
- 시차 없는 시각·누락·잘못된 시각을 판단불가 처리.
- 장비 토큰 인증, 재전송 중복 방지, 다운로드 원본 바이트·해시 일치.
- 결함 승인 요청 409 거부, 보류 및 검토 이력 저장.
- 정상 승인, HTML 문자 이스케이프, CSV 출력.
- 잘못된 JSON, 동일 기준/비교 자료 거부.

브라우저 시험 `scripts/ui_smoke.cjs`는 데스크톱 1440×1050과 모바일 에뮬레이션 390×844에서 다음을 수행합니다.

1. 결함 버전 비교, 승인 버튼 비활성화 확인.
2. 원본 근거 창, 보류 기록.
3. 정상 버전 재검증, 승인, 보고서 새 창 확인.
4. 모바일 레이아웃의 본문 가로 넘침 없음 확인.
5. JSON 업로드·모의 장비 전송의 중복 처리 확인.
6. 브라우저 JavaScript 예외 없음 확인, 매뉴얼용 화면 캡처.

## 해석의 한계

테스트의 성공은 합의한 데모 범위에 대한 확인입니다. 다양한 장비·고주파 데이터·동시 접속·대량 저장·실제 휴대폰 하드웨어·고객망 방화벽·SECS/GEM·EDA·센서 교정·생산 품질·보안 인증은 시험하지 않았습니다. 모바일은 Chrome의 화면 크기·터치 에뮬레이션이며 실제 휴대폰 접속은 같은 네트워크에서 추가 확인해야 합니다.

프런트엔드 의존성은 취약점 확인 후 Vue 3.5.44·Vite 6.4.5로 갱신했고 해당 lockfile의 npm audit는 0건이었습니다. 이것이 전체 소프트웨어나 Docker 이미지에 취약점이 없다는 뜻은 아닙니다. 별도의 운영 보안 심사는 수행하지 않았습니다.

기준·결함·정상 자료를 다시 전송하면 저장 건수를 늘리지 않고 기존 자료를 사용합니다. 브라우저 시험으로 생성한 데모 검증과 검토 기록은 이력 메뉴에 남아 있습니다.
