# 고객 시연 영상

## 완성본

- `TraceProof_고객시연_여성내레이션.mp4` — 약 3분 28초, 1920×1080, H.264 영상·AAC 음성.
- 한국어 여성 AI 내레이션 `ko-KR-SunHiNeural`과 영상에 삽입된 한국어 자막을 포함합니다.
- `TraceProof_고객시연_재생.html`을 브라우저에서 열거나 MP4를 동영상 플레이어에서 재생하세요. 인터넷 연결 없이 재생할 수 있습니다.
- `TraceProof_고객시연_자막.srt`는 편집·번역용 별도 자막입니다. 완성 MP4에 이미 자막이 있으므로 함께 켜면 두 번 표시될 수 있습니다.
- `VIDEO_SCRIPT.md`는 장면별 시각과 내레이션 대본입니다.

## 보여 주는 내용

고객의 데이터 대조 문제 → 모의 장비 전송 → 승인 기준표 → 변경 전후 검증 → 실패·판단불가 분류 → 원본 근거 → 보류 기록 → 정상 버전 재검증·승인 → 보고서 → 모바일 확인 순서입니다.

장비 로그·데이터 항목표·시험 결과를 따로 대조하는 반복 업무와, 같은 근거로 개발·품질 조직이 설명하는 과정을 어떻게 지원하는지 설명합니다. 실제 실행 중인 MVP를 조작해 녹화했으며, 시작·문제 소개·마무리 화면만 설명용 그래픽입니다.

모든 데이터는 가상의 데모 자료입니다. 특정 고객 납품 실적·인수 합격·수율 개선을 주장하지 않습니다. 실제 장비 프로토콜 연결과 운영용 계정·권한은 현재 MVP의 범위 밖입니다. 영상 녹화 과정에서 데모 검증·검토 이력 2건을 추가했습니다.

## 제작과 확인

제작 소스는 `scripts/video/`에 있습니다. 여성 음성 속성을 확인했고, 실제 화면 12개 장면에서 JavaScript 오류가 없었습니다. 완성 MP4의 전체 디코딩, 음성 스트림·음량, 장면별 자막 배치와 브라우저 재생을 확인했습니다. 평균 음량 -16.6dB, 피크 -1.5dB였고 브라우저는 1920×1080·208.22초로 읽어 재생했습니다. 세부 규격·장면 시각은 `TraceProof_고객시연_제작정보.json`에 있습니다.

재제작에는 실행 중인 MVP, Node·Playwright·Chrome, 한국어 글꼴, Python의 edge-tts·imageio-ffmpeg·Pillow가 필요합니다. 음성 합성 때는 네트워크가 필요하지만 완성 영상의 재생에는 필요하지 않습니다.
