# 고객 세일즈용 기능 설명과 시연 대본

완성 영상: [고객 시연 재생](TraceProof_고객시연_재생.html) · [MP4 파일](TraceProof_고객시연_여성내레이션.mp4) · [영상 대본](VIDEO_SCRIPT.md). 약 3분 28초의 여성 AI 내레이션·한국어 자막 영상입니다.

## 설명할 제품

“장비 소프트웨어를 수정한 뒤, 고객에게 제공할 데이터의 단위·시간·작업 연결이 승인 기준과 맞는지 확인합니다. 기존 시험 도구의 결과와 원본 로그를 연결해 미확인 항목과 검토 보고서를 남깁니다.”

첫 고객 가설은 반복 납품·패치가 있는 중소·중견 장비업체입니다. 제조사 EES·품질 조직도 검토할 수 있으나 장비업체 도구를 사용했다고 제조사가 보고서를 받아준다는 뜻은 아닙니다. 기존 도구로 충분한 고객에게 별도 제품 구매를 권하지 않습니다.

## 7분 시연 순서

| 시간 | 화면과 동작 | 설명할 내용 |
|---|---|---|
| 0~1분 | 장비 데이터의 3개 버전·승인 항목표 | 가상 자료이며 어떤 항목·단위·간격을 검사하는지 먼저 합의 |
| 1~2분 | 장비에서 전송 또는 JSON 업로드 | RAW_DATA의 모의 장비가 실제 HTTP로 전송. 같은 원본은 중복 저장하지 않음 |
| 2~3분 | v1.0.0 → v1.1.0 검증 실행 | 데이터 수신 성공과 기준 만족은 다름. 결함과 모호한 자료를 구분 |
| 3~4분 | 실패·판단불가 필터, 원본 확인 | 온도 단위·FLOW 누락·압력 중복·RF 전력 및 Run·시험 버전 증거 확인 |
| 4~5분 | 검토자·의견 입력, 보류 기록 | 결함이 남으면 API에서도 승인 거부. 사람이 확인한 조치를 기록 |
| 5~6분 | v1.0.0 → v1.1.1 새 검증과 승인 | 필수 검사 통과. 진동 범위 미설정은 비필수 미실시로 남음 |
| 6~7분 | 보고서·CSV·원본 다운로드 | 기록된 기준·원본 해시·판정·검토 이력을 전달. 브라우저 인쇄로 PDF 저장 |

화면 캡처는 실제 브라우저 테스트 후 `screenshots/desktop-validation.png`, `screenshots/mobile-validation.png`, `screenshots/report.png`에 있습니다. 캡처의 숫자·시각·검증 ID는 테스트 실행마다 달라질 수 있습니다.

## 고객에게 확인할 질문

1. 최근 출하·패치 1건에서 파일 준비·규칙 정리·대조·보고서 수정에 누가 얼마나 일했습니까?
2. 이미 사용하는 tester·FDC·ALM·Excel 자동화로 안 되는 부분이 구체적으로 무엇입니까?
3. 데이터 사전·Run/Step/Chamber 대응·허용 오차를 확정할 담당자가 있습니까?
4. 장비 원본과 수집 결과를 허용된 환경에서 비교할 수 있습니까?
5. 최종 고객이 어떤 형식과 근거를 받아야 합니까? 이 도구의 결과를 검토해 줄 수 있습니까?
6. 기존 업체 기능 추가 견적과 비교했을 때 구매할 예산·책임자·시점이 있습니까?

## 기능과 사업 효과를 구분해 설명

| 실제 MVP 기능 | 검증할 사업 효과 |
|---|---|
| 규칙 대조와 원본 행 확인 | 담당자의 준비·대조·재확인 시간 감소 |
| 버전 증거·검토 이력 | 잘못된 버전 결과 사용과 설명 자료 재요청 감소 |
| 통과·실패·판단불가·미실시 구분 | 누락·불확실성을 숨기지 않고 후속 조치 결정 |
| 모바일·보고서·CSV | 현장 검토 접근성, 고객별 제출 업무 개선 |

효과 수치는 아직 고객 실증 전입니다. “수율 몇 % 개선”, “삼성·SK 인수 통과”, “공인 SEMI 인증”, “기존 제품에 없는 독점 기능”, “AI가 원인 확정”이라고 설명하지 않습니다. 이 MVP는 새로운 시험 엔진이나 물리 센서 교정기, 사용자 전자서명 시스템이 아닙니다.

## 유료 실증 제안의 경계

장비 1모델·파일 2형식·기준 1개·최대 30개 항목·시나리오 3개 같은 범위를 계약 전에 합의합니다. 현재 제공 데모는 5개 항목입니다. 30개 처리를 실증했다고 주장하지 않습니다.

고객이 기준과 정답을 확정하고 실제 자료 제공 권한을 확인해야 합니다. 고객의 최초 기준 정리·설정·교육·결과 수정시간을 모두 포함해 현행 방식, AI 없는 자동화, 필요 시 AI 추가 방식의 총시간을 비교합니다. 현재 MVP에는 AI가 들어 있지 않습니다.

가격은 이 소스에 포함된 확정 상품이 아닙니다. 고객별 원가와 편익을 산정해 별도 제안합니다. 업무 여력과 실제 현금 절감을 구분하고 줄지 않은 출장·재시험·납기 지연 손실을 효과에 합산하지 않습니다.

## 고객 도입 전 추가 개발

실제 장비 프로토콜, 고객 데이터 파서, 계정·역할·승인 권한·감사 정책, 기준표 개정 승인, TLS·배포 심사, 백업·복구, 대용량 처리, 운영 지원 계약은 별도 범위입니다. 기존 소스 재사용 가능 여부는 코드·사용 권한을 확인한 뒤 판단합니다.
